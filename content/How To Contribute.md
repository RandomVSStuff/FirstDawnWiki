This guide is made for people with little technical experience. Here are some prerequisites, a GitHub account(or any other git service to allow you to make PRs), GitHub Desktop(or any other git service to allow you to make PRs), and Obsidian MD, or another Markdown editor.
	 
## First Steps
After you have the software installed, and a GitHub account created, we can begin work on making your first wiki, first, open GitHub Desktop, and in the top right corner(or on the home page) click clone repository.![[Screenshot 2025-01-31 134052.png]]


Click clone from URL, and insert this link: https://github.com/RandomVSStuff/FirstDawnWiki


![[Pasted image 20250131134302.png]]

Click clone, then contribute to parent project.

Once you have done this, you will want to make a new branch, this branch is where you will work on all of your wiki changes/additions, to do this click the branch icon in the top bar where it says "current branch", then create a new branch, and make a name for it.

![[Pasted image 20250131134555.png]]

> Make sure to click publish branch before beginning work on content.
> ![[Pasted image 20250131134653.png]]

## Writing Content
The content on this website can be categorized into certain areas, or you can even create your own section! Just try your best to follow the norms, or create a new standard :)

You want to open up obsidian md, and click open folder as vault, navigate to where you cloned the wiki, and open up the content folder, and begin editing away!

Quick Guide for Obsidian MD: [Getting Started with Obsidian Notes: A Beginner’s Guide - Obsidian Rocks](https://obsidian.rocks/getting-started-with-obsidian-a-beginners-guide/)
## Adding Content to the website!

Once you have saved your work, and feel like it is ready to be added to the website, you can make your Pull Request(or PR), to do this, go to GitHub Desktop, and make a commit, in the bottom left corner, this can be as detailed or vague as you like.
![[Pasted image 20250131135233.png]]

Once you have your files committed, you can then push it to the GitHub using the push origin button in the top bar.
![[Pasted image 20250131135400.png]]

Once this is done, we can head to the Repository it is saved in: [RandomVSStuff/FirstDawnWiki: Current wiki for the First Dawn Homo-Sapiens Server](https://github.com/RandomVSStuff/FirstDawnWiki), go to pull requests, ![[Pasted image 20250131135532.png]]
